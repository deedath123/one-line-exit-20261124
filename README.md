## How it works

`main.py` (Python standard library only) writes the single entry line above to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.
The entry is exactly 125 characters / 125 bytes, one line.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
